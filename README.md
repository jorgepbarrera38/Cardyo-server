# Cardyo – Backend

Backend desarrollado con Laravel para un sistema de gestión de gimnasios, orientado a la administración de clientes, membresías, pagos y control de acceso.

La solución permite centralizar la información administrativa y financiera del gimnasio, facilitando el seguimiento de las membresías y el registro de ingresos.

## Funcionalidades principales

- Registro y administración de clientes.
- Configuración y gestión de tipos de membresías.
- Control de membresías activas.
- Consulta del historial de membresías.
- Registro y seguimiento de pagos.
- Validación de ingreso de clientes mediante documento de identidad.
- Generación de informes de pagos e ingresos.

## Tecnologías utilizadas

- **Lenguaje:** PHP.
- **Framework:** Laravel 8.
- **Base de datos:** MySQL.
- **Autenticación:** JWT.
- **Exportación de información a Excel:** Maatwebsite Excel.

## Arquitectura

Este repositorio contiene el backend de una aplicación web que expone servicios mediante una API REST, consumida por una interfaz desarrollada con Vue.js.
